# c-algorithmic-exercises
A collection of small practice programs created during my C learning journey.

## 📂 Projects

- **01_gpa_calculator:** Calculates GPA based on course grades and credits using modular files (`.c` and `.h`).
- **02_atm_simulation:** A menu-driven ATM application for checking balance, depositing, and withdrawing money.
- **03_binary_to_decimal:** Converts binary numbers into decimal format.

## 🚀 How to Run
```bash
gcc main.c -o program
./program
